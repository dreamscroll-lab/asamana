# 世界地图规范

[English](README.md) | 简体中文

**一张世界地图 = 地图本身 + 一套角色**

一张地图可以被很多个叙事主题反复使用。所以制作地图资产的时候不应该绑定任何特定的主题。

地图一般只需要制作地形、路、建筑、静态基础设施、环境（树、草）和角色等等，至于角色如何移动，角色如何与环境交互，角色如何行动，这个是由叙事引擎完成的，地图不需要管。总的来说，**地图尽量基本，简单，通用。**

---

## 1. 一张地图长什么样

```
worlds/templates/<地图名>/
├── map.tmj          # 文件名固定
├── tilesets/        # 地图美术，路径随 .tmj 里写的相对路径
└── characters/      # 角色美术 —— 见 CHARACTER_ASSET_SPEC.md
    ├── characters.json
    └── *.png + *.xml
```

**怎么装进来**：把目录拷进 `worlds/templates/`，或者压成 zip 从**地图工作台**（`#/lab`）点
「Import map」。两条路都会跑同一个校验器——导入是在它**落地之前**跑，不合格就列出问题清单，
一个字节都不会写进来。

```bash
.venv/bin/python -c "from worlds.template_check import check_template; print(check_template('你的目录名') or 'OK')"
```

**刷新页面即可在地图选择器里选到它**——列表每次请求扫盘，不用重启服务。

**删除**：地图工作台里点「Delete」，或者直接把目录删掉。**已经建成的世界不受影响**，因为每个世界
在初始化时就把地图和它的美术以及角色资产都**冻结**成了自己的一份副本，跑起来读的是自己副本，所以删掉一张图
只是失去了再用它建新世界的能力。

**`<地图名>`**：`^[a-z][a-z0-9_]{0,63}$`，单层目录名（`metro`、`changan_iso`）。它是**纯代码层
代号，不出现在界面上**，界面显示的是 `world_name`。地图建议用 Tiled 工具打开查看编辑。

**两个名字都必须唯一，导入时会拦：**

- **目录名**已被占用 → 拒绝。**导入永远不覆盖已有的地图**。
- **`world_name`** 已被别的地图用了 → 拒绝。

## 2. 投影与画法

### 投影只支持等距（isometric）

投影只支持 Isometric，其他投影方式的不支持。

原因是角色是按四个等距朝向**逐张画**的，其他投影的地图上没有一个朝向能对上它的四条
正轴。

### 网格尺寸：建议 128×64（2:1），非强制

2:1 是等距美术的标准，建议使用 128×64，当然 64×32 一样跑得通。

### Tileset 必须嵌入

禁止外部 `.tsj` 引用——外部表在 `.tmj` 里没有 `image` 字段，服务端既冻结不了也下发不了，那些格子  
会渲染成空洞。Tiled 里：Tileset 面板 → 右键 → Embed in map。

美术**必须放在地图目录内**，用相对路径引用。tile 尺寸不必等于网格大小，比如高大的建筑本来就该跨格。

### 图层名全局唯一

图层名全局唯一，不同分组下的图层名也不能相同。  
建议按用途分组（`base` / `structures` / `environment`），组名不参与任何逻辑。

## 3. 地图属性（Tiled：地图 → 地图属性）

**八项全必填。** 


| 属性                  | 类型     | 说明                                                                             |
| ------------------- | ------ | ------------------------------------------------------------------------------ |
| `world_name`        | string | **世界地图的名字**，2–6 字。地图选择器上显示的就是这个名字。                                             |
| `era_name`          | string | 时代名，会进叙事引擎，比如`大唐` / `当代` / `2087年`。                                            |
| `calendar`          | string | 日期叫法：`classical_cn`（正月初一）或 `modern`（3月4日）                                      |
| `world_description` | string | 地图的描述，初始化世界时会根据这个描述去选择合适的地图。同时应该描述的是地图，不应该绑定任何主题。这个描述很重要，如果描述写得不准的话会直接影响地图的选择。 |
| `start_month`       | int    | 1–12                                                                           |
| `start_day`         | int    | 1–30                                                                           |
| `start_hour`        | int    | 0–23                                                                           |
| `seconds_per_tile`  | int    | **移动过一个 tile 要多少秒**                                                            |
| `location_aliases`  | string | *选填*。`别称:location_id,…`，给口语指称兜底                                                |


### 一格多久

`seconds_per_tile` 表示的是角色在一个格子上移动要多长时间，可以估算一个格子在现实世界中的距离，再估算常规的移动速度，最后得出这个值。比如唐长安靠两条腿  
（一格约 200 米 → `144`），现代都市有车有地铁（同样的格距 → `60`）。

## 4. 地点

**有且仅有一个**名为 `place` 的对象层（其他对象层可以有，但地点只认 `place`）。

层内每个对象：


| 要求                  | 说明                            |
| ------------------- | ----------------------------- |
| `type` = `location` | Tiled 里的「类型/Class」字段          |
| 有名字                 | 对象的 Name，是**叙事里的地名**（「市立医院」）。 |
| 矩形非零                | 地点是一片**区域**，不是标记点             |
| 在图内                 |                               |


属性五项，其中四项要你填：


| 属性            | 说明                                       |
| ------------- | ---------------------------------------- |
| `location_id` | 小写下划线英文，**全图唯一**。                        |
| `description` | 一句话说清这里是什么、什么样。                          |
| `connections` | **不用填**，导入时会自动算出并写入（第 5 节）               |
| `capacity`    | 容纳人数上限                                   |
| `is_public`   | 是否对外开放。让世界中的角色知道这地方不是谁都能随便进；进不进得去由他自己权衡。 |


**粒度**：地图只提供**稳定的基础设施**，人物/物品/剧情由叙事引擎注入。所以地点名用功能性、地理性  
称呼（「城东工业园」「市立医院」），不绑任何主题的专名或冲突。**20–25 个地点**是验证过的舒适
区间，每个地点连 **3–5** 个邻居。

**整张图必须连通**——任一地点都能走到其他任一地点，否则角色会被困死。

---

## 5. 连接

**`connections` 不用自己写。** 导入时会按地图**自己的地面**算出来并写进去，如果你自己写了也会被换掉，也不用留空属性。

判据是**路径**，不是距离：

> A 与 B 相连 ⟺ 两者之间**最短可走路线**不进入任何**第三个地点**的矩形。比如 A 到 B 的最短路径可以直达，那 A、B 的 connections 就相互包含对方，反之如果最短路径经过 C，即 A <-> C <-> B，那 A、B 的 connections 就不能相互包含对方。

地点是**面**不是点，角色走的是地点的边缘，不是地点的中心。

**为什么不让你写**：在制作地图的时候，其实制作人自己已经设计好路，墙，障碍物等等，哪里可以走通，哪里可以站人，哪里障碍物等等，这些其实在设计的时候都是已经确定了，那这样的话从制作人的角度看，每个地点怎么连接其实已经表达清楚了，而且通过计算也可以直接计算出 connections，所以就没有必要再手动填写 connections 。

> 手动拷贝目录（不走导入）时，自己跑一次：
>
> ```bash
> python -m worlds.connections <地图名>            # 只看推导结果
> python -m worlds.connections <地图名> --write     # 写回（只改这个字段，保留 Tiled 格式）
> ```

## 6. 走与站

### 路面：二选一，不可混用

- **白名单**：给路面 tile 标 `road = true`（表示可以移动通过）
- **黑名单**：给障碍 tile 标 `collides = true`（表示禁止移动通过，禁止站在上面）

图里只要出现**任何一个** `road`，就整体按白名单处理——未标记的格子一律不可走。

> **最容易踩的坑：每一块路面 tile 都要标，不能只标一个。** 街道往往由同一张 tileset 的好几个
> tile 拼成，漏标的那几个整条街都不算可走。

`collides` 在两种模式下都生效：它说的是「这格不能有人」。

### 站人的地面：基本不用标

渲染器直接读你画的美术——**比网格高**的 tile 就是立起来的东西（房子、城墙、树冠），按它像素实际
盖住的格子把地面占掉；**正好一格高**的就是地面本身（地砖、路面、草皮），永不占格。所以你画一座
房子，它脚下和身后的地面自动就不能站人了，一个标记都不用打。

**只有一种情况要你说**：看得见但不能站的**平面**——典型是水面。它是一格高的地砖，图像分不出水和  
冰，只能由制作人给它标 `collides`。只标真正的水面，半岸半水的过渡砖站得住，也该站得住。

### 校验器在这里卡两件事

- **每个地点不能是孤立的，必须要与路面相通**。够不着的话寻路没有起点，去它或从它出发的每一趟都变成直线穿楼。
- **每个地点自己的矩形里至少有 4 格空地**。否则人会被摆到矩形**外面**去。

## 7. 角色

角色美术是地图的一部分，完整规范见  
**[CHARACTER_ASSET_SPEC.md](CHARACTER_ASSET_SPEC.zh-CN.md)**。

一张没有角色的地图不是「简陋的地图」，是一座**空城**——所以缺 `characters/` 是错误，不是降级。

| 报的是                                                   | 去看                      |
| ----------------------------------------------------- | ----------------------- |
| 投影不是 isometric                                        | 第 2 节                   |
| tileset 是外部引用 / 没有 image / 图片找不到                      | 第 2 节                   |
| 图层重名 / `place` 层不是恰好一个                                | 第 2、4 节                 |
| 缺地图属性                                                 | 第 3 节                   |
| 没有地点 / 缺属性 / id 空或重复 / 没名字 / 零尺寸 / 出界                 | 第 4 节                   |
| 有地点走不到（整图不连通）                                         | 第 4、5 节                 |

| 有地点够不着路网                                              | 第 6 节                   |
| 地点矩形里空地不足                                             | 第 6 节                   |
| 角色清单缺失或不合规                                            | CHARACTER_ASSET_SPEC.md |

## 9. 怎么从零做一张地图

### 先想清楚这是什么地方

世界叫什么、什么年代、日期怎么称呼、空间布局是什么样——这四样最后会变成地图属性（第 3 节），  
但要先想清楚，因为它们决定你去找什么样的美术。

### 备齐两套美术

- **地图**：等距 2:1 的 tileset
- **角色**：与地图配套的角色资产（见 [CHARACTER_ASSET_SPEC.md](CHARACTER_ASSET_SPEC.zh-CN.md)）

> 想先把地跑通，可以**临时**拷一份现有的 `characters/` 使用，验证通过了，再制作属于这个世界的角色资产。

### 在 Tiled 里新建

- 方向：**等距（Isometric）**
- 瓦片大小：**128 × 64**
- 地图大小：现有地图两张都是 **48 × 56 格**。（当然可以画更大的地图）

### 铺地，分层

现有地图的分组是 `base`（地面 / 路面 / 水）、`structures`（基础设施、墙、建筑）、`environment`（树、植被装饰）、  
`regions`（对象层）。组名不参与任何逻辑，纯为作图方便而分组。**画的顺序就是渲染顺序，从下往上叠。**

### 标路面——注意标在哪

`road` / `collides` 标在 **tileset 的 tile 上**，不是在地图图层上：Tiled 里打开 tileset、选中  
 tile、加自定义属性 `road`（bool）= true 或 `collides`（bool）= true。

### 画地点

新建一个**对象层**，名字必须是 `place`（放在哪个分组里都行）。在上面画矩形，每个矩形：类型填
`location`，Name 填地点名称，再加四项属性（第 4 节）。`connections` 不用填。

### 边做边验

铺完地就可以跑一次校验器，它会把还没做的事一条条列出来。可以根据校验结果继续完善。

### 看效果

导入地图之后打开**地图工作台**（`#/lab`）：「Cast」是把所有角色资产展开，可以预览效果，也可以预览动画效果。「Scenes」是**真实的渲染器**，这里看到的渲染效果就是进入真实叙事后看到的渲染效果。
