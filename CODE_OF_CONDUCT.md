# Code of Conduct

English | [简体中文](CODE_OF_CONDUCT.zh-CN.md)

This project has adopted the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

All participants in issues, pull requests, discussions and other project spaces are expected to follow it: be respectful, welcome people of all backgrounds and viewpoints, and discuss ideas without personal attacks. Harassment and discrimination are not tolerated.

To report unacceptable behavior, email **finley@dreamscroll.net**. Every report will be taken seriously and handled confidentially.
