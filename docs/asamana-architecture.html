Asamana System Architecture

An emergent narrative engine. Give it a theme and it builds a world full of autonomous agents. Each agent runs its own perceive, decide, act loop, and the story grows out of what they do. Dependencies flow one way: interaction → world, engine, agent → core ← providers.

Narrative Runtime

engine/

Advances the world one step at a time in the background. Each step:

  1. Delivermessages and broadcasts that are due
  2. Pressureassess outside pressure on each agent
  3. Interruptcut actions short when something urgent happens
  4. Schedulechoose which agents act
  5. Planthose agents run their cognition loop
  6. Arbitratesettle conflicts over the same person or object
  7. Executean LLM judges how each action turns out
  8. Carry overresults become what agents perceive next

Agent Cognition

agent/

Every agent thinks with the same LLM-driven loop. Each stage is its own focused LLM call, sequenced by code.

Perceivetake in what is happening
Motivateweigh needs, goals, and feelings
Decidepick one action
Acthand it to the runtime
Feedbackupdate memory, mood, and relationships
↺ repeat
Staged pipelinepredictable control flow instead of an open-ended chat loop
Typed handoffsstructured data between stages keeps errors from compounding
Selective contexteach prompt gets only the state it needs: persona, emotion, goals, relationships, or memories
PersonalityMemoryNeedsRelationshipsGoalsReflection
